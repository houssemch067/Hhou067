DentOrdo - application installable (PWA)

1. Mettez TOUT le contenu de ce dossier sur un hebergement web en HTTPS
   (Netlify Drop, GitHub Pages, Cloudflare Pages, votre propre hebergeur...).
2. Ouvrez l'adresse obtenue sur le telephone ou l'ordinateur :
   - Android / Chrome : menu > "Installer l'application"
   - iPhone / Safari  : Partager > "Sur l'ecran d'accueil"
   - PC / Chrome ou Edge : icone d'installation dans la barre d'adresse
3. Apres la premiere ouverture, l'application fonctionne hors connexion.

Les donnees (patients, ordonnances) restent dans le navigateur de l'appareil :
pensez a utiliser Parametres > Exporter pour faire des sauvegardes.

Pour un vrai fichier APK / publication Play Store : pwabuilder.com
(entrez l'adresse de votre site hebergé).
