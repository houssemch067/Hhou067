Vous aviez l’ancienne application (fichier APK) ?

Vos patients sont enregistrés dans l’ancienne application. Pour les retrouver dans la nouvelle :
  1. Dans l’ancienne application : Paramètres › Données › Exporter une sauvegarde.
  2. Dans la nouvelle : Patients › Importer › choisissez le fichier dentagest-sauvegarde-….json (dossier Téléchargements).
  3. Vérifiez que vos patients sont bien là, puis vous pouvez désinstaller l’ancienne application.

إذا كان لديك التطبيق القديم: صدّر نسخة احتياطية منه (الإعدادات › البيانات)، ثم استوردها في التطبيق الجديد (المرضى › استيراد).

Un problème ?

  • Pas de ligne « Installer l’application » dans le menu : touchez « Ajouter à l’écran d’accueil », puis Installer.
  • Navigateur Samsung Internet : touchez le menu ≡ en bas › Ajouter page à › Écran d’accueil.
  • L’icône n’apparaît pas : attendez quelques secondes, ou cherchez « DentaGest » dans la liste de vos applications.
  • Les menus peuvent avoir des noms un peu différents selon la marque du téléphone (Samsung, Xiaomi, Oppo…), mais les étapes sont les mêmes.
